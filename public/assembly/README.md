# public/assembly — media slots

Everything in here is a **PLACEHOLDER**, generated by
`scripts/build-assembly-placeholders.mjs`. Each file is written at the exact
aspect ratio the slot declares in `content/seed-assembly.json`, so replacing
one with real media is a file swap and never a layout change.

```
portraits/   35  3:4   speaker headshots
interviews/  18  16:10 interview stills (play badge + duration burned in)
partners/    13  3:1   logo wordmarks
documents/    6  17:22 letters + 1:1 crests
media/       30  mixed hero poster, rail, story, focus, journal,
                       past editions, gallery, footer band, page intros
video/        1  16:9  hero-loop.mp4 — the hero background clip
```

## Replacing a placeholder

1. Drop the real file in at the same path (any format the browser reads).
2. If the real asset's aspect ratio differs, update `aspect` on that
   `MediaAsset` in the seed builder — do not force-crop in CSS.
3. Remove `placeholder: true` from that asset so the dashed marker and the
   audit trail clear.

Find every remaining placeholder at any time:

```bash
grep -c '"placeholder": true' content/seed-assembly.json
```

## Video slots

`AsmMedia` renders `kind: "video"` through `AsmVideo`: muted, looped,
`playsInline`, with the poster as the still. Under `prefers-reduced-motion`
it holds the poster and shows an explicit play control. To add another video
slot, set `kind: "video"`, point `src` at the clip and `poster` at a still —
no component changes.
